How This RAG Project Works

Retrieval-Augmented Generation (RAG) solves LLM hallucinations by grounding the AI in external, verified factual data before generating a response.

1

Knowledge Chunking & Ingestion

Institutional college data (admissions, fees, placements, hostel) is parsed into granular passages stored in JSON with tags and categories.

2

TF-IDF Vector Space Modeling

Each chunk is tokenized and transformed into a high-dimensional TF-IDF vector with sublinear term-frequency scaling and L2 normalization using pure NumPy.

tf_idf = (1 + log(tf)) * log((1 + N)/(1 + df))
3

Cosine Similarity Retrieval

When you ask a question, the query is vectorized and compared against all chunk vectors via dot product cosine similarity with hybrid keyword boosting.

cosine_similarity = dot(q_vec, doc_vec)
4

Prompt Augmentation & Synthesis

The top-K most relevant chunks are injected as verified context into the prompt. The response is synthesized with exact facts, numbers, and source citations.
